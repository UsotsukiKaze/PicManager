# 响应式前端架构

实施日期：2026-10-07。新入口采用 Vue 3、TypeScript、Vite、Vue Router、Pinia 和 TanStack Vue Query，同源调用现有 FastAPI 接口。

## 当前实现范围

Vue 已接管应用入口、导航、身份状态、首页、图库筛选、图片卡片和双卡片详情。个人中心使用原生页面外壳，按需嵌入现有个人资料/审核工具，无需加载其他业务控制器。分组/角色/特征管理、上传、查重、Pixiv 和设置保留成熟的业务控制器，通过 `compat/bridge.ts` 按需接入一个独立 DOM 容器；这些业务页面尚未全部改写为 Vue 组件。原有登录页及嵌入式个人中心继续使用既有接口。

兼容容器只插入仓库内的静态模板，先加载依赖再初始化控制器；不运行旧版整站启动函数。控制器的写操作和后台 Pixiv 入库完成事件会使新图库缓存失效。离开页面前保存 Pixiv 阅读位置、停止媒体观察和 Temp 预校验；异步模块晚到时不会重新启动已经离开的页面任务。旧图库隐藏容器不再重复加载图片列表。

## 状态和请求

- **Pinia**：身份、侧栏收起状态、图库筛选和页码。页面详情、弹窗、输入草稿保存在组件内。
- **Vue Query**：首页统计、列表、图片详情和标签目录。查询键包含身份、查询条件和页码；读取请求共用缓存，写入不自动重试。
- **搜索**：250 ms 输入防抖；参数变化或离开图库会取消旧请求。加载下一页时保留旧结果，避免白屏；过期响应不能覆盖当前结果。
- **目录**：角色、分组、特征分别分页读取并按 ID 去重，显示最多 60 个下拉选项，避免创建大量 DOM。昵称、别名和拼音仍可检索；新旧页面共用仓库内固定版本的拼音词库和去重加载器，Vue 选择器只在输入英文字母时加载，每批数据只建一次索引。兼容编辑器随后打开时复用已加载脚本；失败允许重试。超过 10,000 个标签会明确报错，不悄悄截断。
- **身份**：启动认证请求去重；账号或权限变化取消请求并清空缓存。已启用旧控制器时重新加载页面，清除其账号相关状态。更新昵称等个人资料保持页面容器挂载。
- **路由**：使用 hash 路由，不要求反向代理增加 SPA 通配回退。API 的 404、资源、登录和授权回调路由保持独立。图库查询条件进入 URL，支持浏览器前进/后退；页面切换保留阅读位置。

## 图片加载

图库每页先加载 20 个轻量卡片；图片使用裁剪展示、浏览器懒加载和异步解码。`GET /api/images/search?view=card` 只返回编号、PID、尺寸、分级、角色/分组展示信息和画师身份；不读取昵称、Pixiv 标签 JSON 和图片特征关系。20 张卡片的隔离数据库测试只产生计数和列表两次 SELECT。旧调用不带 `view` 时仍返回完整结构。

点开后才请求完整详情：先从原卡片位置展开模糊缩略图，再加载现有清晰 WebP 预览；预览失败或返回带缺失标记的 HTTP 200 占位图时回退原图。图片底部中轴的淡灰色亚克力胶囊按钮可主动切换原图，加载时显示旋转反馈，完成后收窄为“原图”状态，翻图重新使用预览。预览请求可取消，临时 Blob URL 在翻页和关闭时释放。详情和图片是独立卡片，详情顶部跟随图片顶部，图片区保持在页面中轴，箭头与关闭按钮在图片区。校验状态只在详情展示。R16/R18 在卡片和详情内使用亚克力模糊缩略图，R16 保留原有颜色与亮度，R18 额外降低亮度；显式揭示前不请求清晰预览或原图，也不显示原图按钮，切换到下一张受限图需要再次揭示。

这次重构没有提高 Pixiv 外部请求并发，也没有改变服务端媒体缓存、队列或代理参数。外部网络瓶颈应通过现有诊断单独测量。

## 构建与部署

开发环境需要 Node 22.12+，本轮使用 Node 24。固定依赖由 `frontend/package-lock.json` 管理；TypeScript 使用 5.9，与当前 Vue 类型检查器匹配。

```bash
cd frontend
npm ci
npm run dev
```

开发页为 `http://127.0.0.1:18877/static/app/`，默认将 API 和旧版资源代理到 8777。可用 `PICMANAGER_API_URL` 指定单独开发服务；开发代理会真实访问该服务，不应指向生产数据库进行写操作。

```bash
npm run build
```

构建产物放入 `static/app/`，与源码一起纳入 Git；修改前端后必须重新构建并一起提交。FastAPI 优先分发该入口，缺少产物时回退原入口。Python wheel 已包含整个 `static`，生产运行不需要 Node。新 JS/CSS 使用内容哈希文件名和一年 immutable 缓存；HTML 每次重新验证。旧模板 `/static/index.html` 用于兼容容器和回退，继续保留。

发布时一起部署 HTML 和全部 assets，保留旧哈希文件直至旧页面失效，可避免已打开页面延迟加载旧 chunk 时出现 404。前端资源变化需要构建，服务入口变化需要按原部署方式重启 Python 服务。2026-10-07 按用户要求将已提交重构和本轮界面修改同步至本机 `D:\A_Projects\PicManager` 的 8777 实例，保留旧哈希资源供已打开页面使用；同步前保存数据库快照。本轮界面修改与构建产物一起提交发布。
