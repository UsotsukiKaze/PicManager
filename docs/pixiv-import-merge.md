# 优选夹相似图片入库

每页入库前，复核 dHash 候选和推荐页使用的轻量画面指纹。指纹索引覆盖已有的无 PID 图片，因此不同分组的截图、不同分辨率原图也能进入比对。提示仅作候选，未经用户确认不会合并或删除文件。

任务进入持久化 `awaiting_duplicate` 状态后，Pixiv-ol 页面自动打开共享的相似图片合并窗。正在阅读其他弹窗时先等其关闭。其他任务继续入库；关闭或“稍后处理”保留本次任务，并可从悬浮入库进度的“比对并合并”继续，不反复自动弹出同一次确认。

左侧并排比对库图和本页 Pixiv 预览，可切换多个库内候选、选择保留文件。右侧选择各项信息来源并实时显示合并结果。角色默认采用保留图的标签，分组、特征可合并；本次确认的 Pixiv PID 固定为标准 `作品ID_pN`。多页作品逐页确认，不把整部作品的角色自动合并到当前页。

- 保留库图：保留原文件，复用既有信息合并服务，补齐本页的 Pixiv 来源、画师和原始标签。
- 保留 Pixiv 原图：复用既有合并服务，先提交新图片、选定标签和来源，再清理被替换文件。写入失败时旧文件仍在；清理失败时旧记录维持归档，新图入库结果记录 `cleanup_pending`。
- 保留两张：作为独立图片入库，记录当前选定候选的不同图片决定。

确认请求绑定任务、账号、用户、页码和本轮比对标识；提交时与实际入库前分别检查候选文件及标签签名。发生变化时重新比对，禁止旧弹窗替换变化后的文件。确认接口采用条件更新，重复提交不会覆盖下一页的待确认状态。

合并界面同样适用于上传和本地维护中的共享相似图片比对。不新增数据库表，决定和待确认状态保存在现有 Pixiv 任务内。
